Administrer, déployer et sécuriser un VPS Debian 13

Un parcours en douze modules pour apprendre à héberger trois applications indépendantes — React + Express, PHP + PDO, Python + FastAPI — sur un même serveur, avec domaines, HTTPS, isolation des comptes, sauvegardes et supervision.

Voir les douze modules Comprendre l'architecture
Laboratoire uniquement. Les procédures du parcours s'exécutent sur un VPS dont vous êtes responsable, ou sur un serveur de test. Aucune commande ne doit être lancée sur une machine que vous n'administrez pas.

Objectifs du parcours

À la fin du parcours, l'apprenant sait :

  • Administrer

    Se connecter, gérer utilisateurs, permissions et paquets sur Debian 13.

  • Sécuriser

    Durcir SSH, appliquer le moindre privilège, filtrer les ports avec un pare-feu.

  • Publier

    Configurer Nginx, le reverse proxy, les domaines et HTTPS avec Certbot.

  • Déployer

    Héberger trois applications isolées avec leurs comptes, services et bases.

  • Automatiser

    Mettre en place Git, la CI/CD, les migrations et le retour arrière.

  • Exploiter

    Sauvegarder, restaurer, superviser et diagnostiquer les incidents.

Architecture de référence

Un point d'entrée public unique (Nginx), trois applications isolées, une base partagée.

Infrastructure visée

Ordre de grandeur indicatif : les caractéristiques réelles se relèvent dans la console de l'hébergeur.

  • Système

    Debian 13 « trixie » (version stable actuelle).

  • Ressources

    Environ 2 vCores, 4 Go de RAM, 40 Go SSD (à vérifier selon l'offre).

  • Socle partagé

    Nginx, MariaDB, phpMyAdmin (tunnel SSH), Certbot, systemd.

Consulter le site en local

Les métadonnées sont chargées par fetch(). Le site doit donc être servi en HTTP : ouvrir index.html par un double-clic (file://) empêche le chargement de modules.json. 

python3 -m http.server 8080

Puis ouvrir http://localhost:8080/ dans le navigateur.
